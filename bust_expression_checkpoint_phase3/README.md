# Ryoko expression phase3: approved checkpoint

This isolated local 2D project preserves all six approved expressions and adds puzzled (EXP-123), flustered (EXP-142), and yawn (EXP-163). The three new expressions were visually approved before publication.

Review previews/EXP-123_approval_comparison.jpg, EXP-142_approval_comparison.jpg, and EXP-163_approval_comparison.jpg. Exact reference crops are beside actual assembled rest, speech, blink and simultaneous speech/blink states. These are sprite composites, not graphical runtime captures.

Puzzled transfers facial acting only; the approved head remains upright despite reference head tilt. Flustered has separate blush layers that remain active through speech and blinking. Yawn is explicitly fixed-jaw: tall dedicated mouth within unchanged jaw geometry, and eyes remain squeezed shut when blink releases.

Existing speech override/rest controls are unchanged. Open project.godot here; --demo cycles all nine profiles. No head/body deformation, continuous eyelid motion, audio phoneme analysis or secondary physics is added. Prior published checkpoints are preserved; this is a separate cumulative nine-expression project.
