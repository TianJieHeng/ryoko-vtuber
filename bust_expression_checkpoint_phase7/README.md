# Ryoko expression phase7: approved checkpoint

Isolated cumulative 2D bust preserving eighteen approved expressions, adding irritated side-eye EXP-045, triumphant grin EXP-104, holding-back-tears EXP-022. User approved these comparison boards before publication.

Comparison boards show exact-reference crops beside registered rest, speaking A, blink and speech+blink composites. They are not graphical runtime captures.

Side-eye uses both irises directed viewer-right, stern uneven brows and closed frown. Triumphant grin uses a tooth-baring symmetric grin with confident narrow eyes. Holding-back-tears uses delicate wet eye rims, tense raised inner brows and closed trembling mouth, without invented flowing tears.

Each has separate blinking and speech-rest restoration. Blink hides open-eye highlights and restores the exact gaze when released. No audio analysis, continuous facial deformation or physics. Open project.godot; --demo cycles twenty-one profiles. User approved this phase; further phases require visual review.
