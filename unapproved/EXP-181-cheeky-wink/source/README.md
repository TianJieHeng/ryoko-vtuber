# Ryoko Cheeky wink: local unapproved source

This package contains the one shared separate-object rig, the twelve previously approved performances, and the new EXP-181 Cheeky wink. EXP-181 and its independent mouth-corner capability remain local and **not user-approved**. An unapproved backup is not approval or publication to the approved runtime.

Open project.godot in Godot 4.6.3. Select Cheeky wink and press Play. The authored 3.10-second performance uses one sustained screen-right wink, an asymmetric smile that widens, one tiny upper-enamel accent, a sealed hold, and neutral recovery. The original 1.90-second source timing was only a proposal. This package does not claim observed normal-speed playback.

The current source verifier is tools/verify_cheeky_wink_scope.py. Run it with Python 3 from any directory. Add --capture-root followed by the actual capture directory to verify the accompanying full/native PNG receipts. No original workspace path is required. CHEEKY_WINK_STATUS.json and RELEASE.json describe the current unapproved scope. CHEEKY_WINK_DELIVERY_OVERLAY.json records all changes from the frozen captured source. The profile changes are prose spacing only: every key, control, phase, duration and registry entry is unchanged.

All 182 inherited PNGs and all twelve previous performance definitions remain byte-identical. The new corner controls use rigid owners, fixed UV and the unspent bilateral 12 px corner-lift budget. A skin wedge at simultaneous maximum opening, spread and corner lift is inherited and is not repaired here; the reviewed EXP-181 poses avoid it. No whole-mouth rotation, face swap, art edit, head/neck motion or anatomy opacity fade is used. No socket, AI/TTS connection, CI or remote execution is included.
