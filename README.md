## Current delivery

This initial pass contains the phased build plan and the six user-supplied reference PNGs, preserved unchanged with an inventory and visual review. The plan targets 200 expression performances with nine-key-pose motion sheets, plus modeling and facial-control reference packs.

**Planning is not production completion.** No new images, animation frames, mesh, UV textures, Blender rig, shape keys, weights, physics or runtime export have been created in this pass. No tracking compatibility has been tested. The planned 1,800 panels are visual key-pose references, not automatically rigged animations.

Design variants, avatar coverage and the target runtime/tracking route must be settled before dependent production work. Image generation starts only after plan approval. Kimi is the user's intended Blender build workflow; this repository publication does not send it a task or start a build.

No CI or GitHub Actions. Preserve reference originals and record actual native image dimensions for future assets.
