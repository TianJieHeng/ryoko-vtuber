# Diagnostic artwork previews

These contact sheets show the accepted separated head, body, hair, accessory and effect artwork against neutral gray. They are for inventory and edge inspection, **not an assembled avatar, registered layer stack, UV atlas or rendered Blender result**. Each thumbnail is independently cropped to its visible alpha bounds and resampled to fit the preview cell. Original PNG files are unchanged. Full filenames and native dimensions are printed below each part. See `preview_sources.json` for exact source hashes.
