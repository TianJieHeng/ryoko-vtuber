## Launch

Open `ryoko_object_rig/project.godot` in Godot4.6 and run the project, or run `godot --path ryoko_object_rig`. The default scene is now `full_body/full_body_viewer.tscn`. Choose any of the47 approved expressions and press Play or P. Space stops playback. The original27 manual face channels, auto-blink, body controls and approved small bounce operate on this same model. The original bust-only `expression_viewer.tscn` remains an explicit alternative.

The original control bridge is opt-in with `-- --control-port PORT`. No listener is started by default. Its command handling was checked in memory, not through a network socket.
