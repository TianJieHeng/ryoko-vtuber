Vertical style, tongue rise, the 12-pixel corner budget, 40-pixel oral-rise budget, pressure depth, 0.55 opening factor and 30.8-pixel maximum aperture retain their old semantics. All five materials use the same side-specific inverse horizontal map without changing pigment UV. Fixed front/root enamel transforms remain fixed; wing height and rotation remain tied to legacy s. Existing inherited zero-width wedge/purse differences remain unchanged. General open-plus-width support is not advertised.

Manual transactions validate the complete prospective pose before changing ownership, clocks, blink intent or renderer state. Omitted manual fields are retained; reset starts from zero. REST/RELEASE/NEUTRAL mouth aliases close the mouth. For example, setting positive width while retained opening is positive rejects atomically. Setting opening to zero and a positive width in the same request succeeds. A formerly manual opening does not reappear on release: the shared player still releases to neutral. Invalid numeric types, booleans, infinities and out-of-range values reject without partial state changes.

Profile keys default omitted fields to zero. Every adjacent smoothstep segment is validated, not just its endpoints. A segment cannot contain positive opening at either endpoint and positive width at either endpoint. Profiles changing domain need an explicit zero opening/width key between the two segments. Other acting need not be neutral at that key. All fifteen existing profile files and their catalogue entries remain exact, including the explicitly unapproved EXP-158, EXP-181 and EXP-102. No new expression or EXP-116 timeline is registered here.

Trigger/retrigger plans are fixed from the currently displayed source trio and the entire incoming timeline. Old transitions with no width anywhere retain the literal legacy branch. If positive source width encounters any target opening, or positive source opening encounters any target width, a staged bridge first eases the source trio to zero, then eases in the sampled target trio. Other width-participating transitions use a direct trio bridge. Both new modes last `min(0.30, target duration)` seconds and use the raw target sample, never an already restart-blended sample. Target time advances normally. The mode never flips when a delayed opening first appears, and a large time step need not visit the midpoint.

Only opening and the two new widths use the new bridge. All remaining old channels, including smile, corners, purse, pressure, oral lift and other acting, retain their literal 0.30-second restart arithmetic. Their historical completion snap for synthetic definitions shorter than 0.30 seconds is unchanged; the width-participating trio completes continuously even for those targets. All fifteen real profiles last at least 1.9 seconds. Release and interrupted retrigger preserve displayed values and the existing auto-blink restoration policy. Read-only `mouth_transition` state reports mode, stage, duration and the trigger-fixed classification rule without changing existing phase names.

The viewer disables conflicting sliders without silently resetting another value. It labels width as sealed-mouth only. The shared validator remains authoritative for the viewer and local bridge. Internal face setters are geometry helpers, not separate public control transactions. The controller validates the complete pose and then commits the existing setter sequence synchronously, without a yield or partial-state domain guard.
